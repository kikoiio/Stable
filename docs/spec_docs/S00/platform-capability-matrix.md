## 3. 逐行能力详述

每行小节统一字段(顺序固定,便于跨行对照):

- **范围界定**:该行包含什么、不包含什么
- **Linux 状态与证据**:状态 + 证据(文件级引用 + 行为描述)+ 证据类型
- **macOS 状态 / Windows 状态**:本阶段均为「未评估(计划评估)」
- **等价机制线索**:来自路线图与公开机制的提示,**未经验证,不构成承诺**
- **安全不变量**:≥1 条,任何平台实现都必须保持的不可协商保证
- **能力不可用行为**:fail closed——禁用哪些功能、如何向用户说明
- **验收条件**:编号条目;声明「支持」须满足该行全部条目,声明「降级」须满足标注〔降级〕的子集

**状态取值**:`支持 / 降级 / 不支持 / 未评估(计划评估)`;Linux 列不得使用「未评估」。
**证据类型**:`可运行验证`(附命令或测试名,撰写时在本机跑通)/ `仅代码审阅`(附不可运行原因)。
**验收条件编号**:`AC-<域>-<序号>`;域缩写与行对应:C01=PATH、C02=IPC、C03=LOCK、C04=PROC、C05=SECRET、C06=ROOT、C07=CAND、C08=NET、C09=KCAD、C10=GUI。编号一经使用不重命名。
