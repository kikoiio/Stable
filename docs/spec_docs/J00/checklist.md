# J00 云端兼容性与候选隔离试验 Checklist

> 每一项通过运行代码或观察行为来验证，聚焦系统行为。当前仅完成规格设计，所有条目待开发后执行。

## 实现完整性

- [ ] **C01（AC01）环境可重复**：在干净 Ubuntu x64 runner 记录客户端版本、包 SHA-256、runner、夹具摘要和探针版本；第二次运行不依赖残留（验证：查看 J00 JSON 报告与 workflow 运行记录）。
- [ ] **C02（AC02）能力发现可分类**：客户端、CLI、MCP/桥接、隐藏窗口和扩展能力分别得到 `verified`/`limited`/`unavailable`/`unverified`，并区分未安装、需激活、失败（验证：运行发现探针和 fake backend 分类测试）。
- [ ] **C03（AC03）工程识别正确**：授权目录内的 `.eprj3` 格式、入口、文件集、工程身份、器件、参数、引脚、网络和文档范围符合独立预期；越界/损坏/缺依赖被拒绝（验证：夹具校验 + 真实读取结果对照 `expected.json`）。
- [ ] **C04（AC04）修改范围受控**：参数修改要求候选身份、目标对象和期望旧值匹配；不匹配时无写入副作用且有证据（验证：fake backend 的旧值/越界场景和真实操作前后摘要）。
- [ ] **C05（AC05）保存后可重开**：保存后的候选由新会话重开，读取结果确认参数持久化；返回成功但重开/读取失败记为不通过（验证：真实闭环报告中的 save/reopen 快照）。
- [ ] **C06（AC06）检查与导出分离**：规则、网络/结构、BOM、网表、截图、报告各有独立结果；产物非空、格式正确、来源与当前候选摘要一致（验证：逐项检查结果和 artifact manifest）。
- [ ] **C07（AC07）候选隔离成立**：独立 profile、候选路径、身份、自动保存/恢复和桥接不会改变正式工程或关联云端对象；全离线覆盖明确（验证：正式根/身份前后摘要、隔离日志和离线观测）。
- [ ] **C08（AC08）中断可恢复且清理真实**：超时、崩溃、取消、重启后重新观察状态，不盲目重放；客户端、桥接、显示服务和子进程均退出（验证：故障 fixture 与最终进程查询）。
- [ ] **C09（AC09）报告可复现**：同一 workflow 可重复运行，生成脱敏日志、能力矩阵、报告和必要产物，包含提交 SHA、环境、版本、摘要、退出状态和清理结果（验证：两次 workflow 只读比较）。
- [ ] **C10（AC10）退出闸门正确**：至少一条读取→修改→保存→重开→检查→导出闭环和隔离/清理通过；否则报告阻塞原因，后续写入能力保持关闭（验证：兼容性报告逐项结论）。

## 集成

- [ ] **C11 阶段调用链完整**：环境准备、夹具校验、隔离、发现、读写、重开、检查、导出、清理和报告按固定顺序执行；关键失败会停止后续写入假设（验证：fake backend 事件序列）。
- [ ] **C12 证据绑定完整**：每个能力结论引用当前客户端/探针/夹具/工程摘要及相应日志或产物（验证：报告引用解析与摘要重算）。
- [x] **C13 数据边界符合约束**：workflow 使用 `contents: read`、不读取 secrets；公开 artifact 不含真实工程、profile、token 或 provider 密钥（证据：Run 38071508148 配置与 artifact sensitivity scan）。
- [ ] **C14 旧系统无回归**：J00 只增加独立脚本/夹具/工作流，不改变 Stable 运行时；现有定向 Go/Python 检查继续通过（验证：受影响测试与 `git diff` 审查）。

## 端到端场景

- [ ] **E01 正常闭环**：授权 workflow → 公开夹具读取 → 受控参数修改 → 保存 → 新会话重开 → 检查/导出 → 隔离核验 → 清理，得到可审阅报告（验证：一次真实云端 workflow）。
- [ ] **E02 能力缺失**：客户端未安装、接口不支持或需激活时，报告明确原因，流程停在可解释状态，不产生越界写入（验证：禁用能力或 fake backend 场景）。
- [ ] **E03 状态不明**：命令超时/客户端崩溃/用户取消后，系统重新观察实际工程状态，旧 session/generation 不被重放，最终资源清理可见（验证：故障 workflow 或等价受控测试）。
- [ ] **E04 身份/路径破坏**：候选身份不符、正式根被替换或检测到外部修改时，隔离验证失败，正式工程保持不变，J01 闸门不开放（验证：隔离攻击 fixture）。
- [ ] **E05 产物错误**：截图来自错误文档、导出为空或摘要过期时，产物被标记无效，整体交付不记为通过（验证：伪造产物来源/摘要场景）。
