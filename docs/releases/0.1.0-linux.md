# Stable v0.1.0 Linux 发布说明

Stable v0.1.0 提供 Linux x86_64 CLI。此包仅在 Ubuntu 26.04 x86_64 构建和验收；没有据此声明其他发行版、macOS、Windows 或 ARM64 已受支持。

## 下载与校验

从 [GitHub Release v0.1.0](https://github.com/kikoiio/Stable/releases/tag/v0.1.0) 下载下列两个文件：

- `stable-0.1.0-linux-amd64.tar.gz`
- `stable-0.1.0-linux-amd64.tar.gz.sha256`

在下载目录执行：

```bash
sha256sum -c stable-0.1.0-linux-amd64.tar.gz.sha256
tar -xzf stable-0.1.0-linux-amd64.tar.gz
cd stable-0.1.0-linux-amd64
./install.sh
export PATH="$HOME/.local/bin:$PATH"
stable doctor
stable config init
```

编辑 `~/.config/stable/config.json` 填入 provider、model 和凭据，再运行 `stable config check`。运行时还需要 Python 3、KiCad 9、Xvfb、`xvfb-run`、`xprop`、`xwininfo` 和 ImageMagick `import`。

重新解包较新版本并运行其中的 `install.sh` 可升级；已安装的旧版本目录会保留，可重新运行该目录的安装器回退。`stable-uninstall` 移除 Stable 程序，但保留用户配置与运行数据。

## 验收证据

功能代码 SHA `8a4427f91246a1f239505c2a00e02f7e82a691f9` 的 Linux 验收记录如下：

- Go build、全量单测、remote UI 回归、真实 Linux PTY 与发布包安装/CLI/E2E/restart：[Go run 38035716679](https://github.com/kikoiio/Stable/actions/runs/38035716679)，两个 jobs 均通过。
- 普通任务、目标任务、session 回归与完整 M07-C runtime 重启：[E2E run 38035716717](https://github.com/kikoiio/Stable/actions/runs/38035716717)，七个 jobs 均通过。
- Linux workspace writer sandbox 与真实受限 volume：[M09 Workspace Linux run 38035724944](https://github.com/kikoiio/Stable/actions/runs/38035724944)，`writer-sandbox-volume` 通过。

Release asset 包含 tar.gz 与配套 `.sha256` 文件；发布前已下载并验证两者匹配。`.sha256` 附件是此发布包的权威摘要。安装与包内验收由 Go workflow 的 `test-package` job 执行。

## 支持范围

此发布只关闭 Linux x86_64 功能与运行时验收。Darwin、Windows、其他 Linux 发行版和 ARM64 主机验收仍暂缓；Linux 验收结果不表示这些平台兼容。
