# M07-A 技能(Skills)与命令关联 Checklist

> 状态:待验收。基于已批准的 [spec.md](spec.md)、[plan.md](plan.md) 和 [task.md](task.md)。每一项通过运行代码或观察行为来验证,聚焦系统行为;验收时逐项记录证据。

## 技能发现与解析

- [ ] **C01 / AC1**:两种布局(SKILL.md、skill.yaml+prompt.md)技能均被发现与解析;缺 name 回退目录名、缺 description 回退正文首行。(验证:构造两种布局与缺省字段技能,断言解析元数据与 `/skills` 列表)
- [ ] **C02 / AC1**:同名技能项目级覆盖用户级;两种布局并存时 SKILL.md 优先;来源层级与覆盖/并存可在列表或报告观察。(验证:两层同名放置,断言来源与优先级)

## 斜杠命令关联

- [ ] **C03 / AC2**:每个技能注册同名斜杠命令,`$ARGUMENTS` 替换与无占位符追加两种形态正确。(验证:单测两种形态;e2e 展开文本进入会话)
- [ ] **C04 / AC2**:与内置命令、自定义命令文件同名时按「内置>命令文件>技能」跳过,冲突可观察。(验证:构造同名三级冲突,断言补全归属与状态栏报告)
- [ ] **C05 / AC2**:`/skills` 列表与实际技能一致(名称、描述、来源、调用提示),含当前会话已激活;`/skills reload` 报告数量变化。(验证:e2e)

## LoadSkill 工具

- [ ] **C06 / AC3**:对已知技能返回「# Skill: name」+正文并产生激活;对未知技能返回明确错误并列出可用技能名。(验证:单测两路径;e2e agent 调用)
- [ ] **C07 / AC3**:`load_skill` 在 chatserve 与 runtime 两处白名单均可见。(验证:两处 schema 测试断言)

## 会话暴露

- [ ] **C08 / AC4**:会话首次运行的模型请求含技能清单段(名称、描述、when_to_use)。(验证:fake provider 捕获请求断言)
- [ ] **C09 / AC4**:会话进行中新增技能后,下一轮请求出现该技能提醒;同一技能不重复提醒。(验证:e2e 两次请求对比)
- [ ] **C10 / AC4**:`skill_inventory`/`skill_delta`/`skill_invoked` 落会话日志,重启后投影与渲染一致。(验证:e2e 重启前后 transcript 对比)

## 激活语义

- [ ] **C11 / AC5**:斜杠命令激活后,渲染正文作为用户消息进入当前会话且 agent 下一轮可见。(验证:e2e fake provider 断言收到正文)
- [ ] **C12 / AC5**:激活记录随会话持久;触发压缩后,后续请求仍含已激活技能清单(可感知名称,正文可经 LoadSkill 重取)。(验证:注入超长对话触发 boundary 后断言请求内容)

## fork 字段

- [ ] **C13 / AC6**:fork 技能可被发现、列出;slash 与 LoadSkill 调用均返回「子 agent 能力未启用」;不产生会话消息与激活记录。(验证:e2e+事件日志断言)

## 有界性与异常

- [ ] **C14 / AC7**:超限(数量/单文件大小)与异常(symlink、不可读、frontmatter 非法、正文缺失)技能被跳过且路径原因出现在报告;TUI 与服务不崩溃、输入不阻塞。(验证:单测全套异常夹具)

## 热更新

- [ ] **C15 / AC8**:运行中修改技能正文,下次调用即读到新正文。(验证:e2e 修改后 LoadSkill 对比)
- [ ] **C16 / AC8**:新增/删除技能目录后无需重启,补全与 `/skills` 即感知;`/skills reload` 手动触发生效。(验证:e2e)
