# M07-A 技能(Skills)与命令关联 Spec

> 状态:已批准(2026-10-06)。依据迁移地图 M07 行及三子项拆分决定(M07-A skills+命令关联 → M07-B hooks → M07-C MCP,各子项独立走 spec/plan/task/checklist);用户已确认:skills 只做 inline(fork 留 M09)、InstallSkill 推迟、MCP 加载策略为 eager+dispatch(属 M07-C,本项不涉及)、技能文件两种布局都迁、agent 暴露采用全套(清单注入+delta 通知+LoadSkill 工具)、命令冲突优先级为内置>命令文件>技能、激活语义为会话消息+压缩保留。plan/task/checklist 待批。

## 背景

Stable 经 M00–M06 已具备统一 agent 执行、工具协议与权限审批(M03/M04)、持久会话与压缩(M05)、统一命令注册表与自定义命令热更新(M06)。技能(skills)是可复用的提示词包:用户把特定工作流写成结构化文档放进技能目录,agent 能发现并按需加载其正文,用户也能经斜杠命令直接调用。M06 已明确把技能目录发现、skills 与命令的关联、`/skills` 命令留给 M07。

mewcode 源端 `internal/skills` 提供完整行为参照:两种文件布局、两层目录合并、两阶段加载(frontmatter 常驻、正文现读即正文级热更新)、inline/fork 两种执行、技能注册斜杠命令、目录 mtime 增删检测。其中 fork 执行依赖 M09 的子 agent 能力,网络安装(InstallSkill)涉及外部下载——两者均不在本项范围。

本项为 M07 三个子项中的第一个(M07-A),后续 M07-B(hooks)、M07-C(MCP)独立走各自规格。

## 目标

- 技能目录发现:项目级与用户级两个技能目录,按名称项目覆盖用户,与 M06 命令目录惯例对齐。
- 两种文件布局(SKILL.md 与 skill.yaml + prompt.md)的解析与 frontmatter 默认值回填。
- 每个技能注册同名斜杠命令,与内置命令、自定义命令文件的冲突优先级明确且可观察;提供 `/skills` 列表与手动 reload。
- agent 经 `LoadSkill` 工具主动加载技能正文;会话启动时注入技能清单,会话中新增技能经系统提醒通知。
- 技能文件变更无需重启即生效:正文现读、目录增删自动感知、手动 reload 兜底。
- inline 激活语义:正文作为用户消息进入当前会话,激活记录随会话持久并在压缩后保留。

## 功能需求

- F1 技能发现与解析:扫描项目级 `<项目根>/.stable/skills/` 与用户级 `~/.config/stable/skills/` 两个技能目录,每个直接子目录为一个技能,两层合并按技能名称去重,项目级覆盖用户级。支持两种布局:① 目录下 `SKILL.md`(YAML frontmatter + 正文);② 目录下 `skill.yaml`(元数据)+ 可选 `prompt.md`(正文)。frontmatter 字段:`name`、`description`、`when_to_use`、`tags`、`mode`;缺省回填:缺 name 用目录名(小写连字符规范化),缺 description 用正文第一个非空非标题行。`mode` 缺省为 inline;`context`/`fork_context` 作为 fork 遗留字段解析并保留(F6 限定其行为)。同名技能解析冲突(如两种布局并存)时 SKILL.md 优先且可观察。
- F2 斜杠命令关联:每个技能向命令注册表注册同名斜杠命令,描述加技能标识后缀,参数按 `$ARGUMENTS` 渲染(与 M06 自定义命令同语义:正文含占位符则替换,无占位符且有参数时追加为用户请求段)。同名冲突优先级:内置命令 > 自定义命令文件 > 技能命令,被跳过的技能命令可观察(列表或日志中可见冲突原因)。`/skills` 内置命令无参列出全部技能(名称、描述、来源层级、调用方式)及当前会话已激活技能;`/skills reload` 手动触发重载并报告数量变化。
- F3 agent 主动加载:`LoadSkill` 工具(read 类)参数为技能名称;调用后加载该技能正文,经 inline 语义激活(F5),工具结果返回技能标题与正文。未知技能返回明确错误并列出可用技能名。该工具进入 chatserve 与 runtime 两处工具白名单。
- F4 会话暴露:会话首次运行时,agent 上下文包含可用技能清单段(名称、描述、when_to_use,及斜杠命令调用提示),清单在会话内按快照稳定,不因正文修改而抖动。会话进行中新出现的技能,在下一轮运行前以系统提醒形式告知 agent(通知只发一次,不重复打扰)。清单注入与提醒均落会话事件,重启后投影一致。
- F5 激活语义:技能激活时,渲染后正文作为一条用户消息进入当前会话(与 M06 自定义命令执行同语义),agent 下一轮即可见;激活动作与消息落会话日志。当前会话的已激活技能清单随会话持久;会话压缩后,已激活技能的名称与正文仍对 agent 可感知(具体保留机制留 plan),`/clear` 类清空语义按 M05 现有行为处理。
- F6 fork 字段行为:`mode: fork` 或 `context: fork` 的技能可被发现、列出、注册命令;经任一入口调用时返回明确错误「子 agent 能力未启用(fork 模式留待 M09)」,不进入会话、不产生激活记录;错误可观察。

## 非功能需求

- N1 一致性与审计:技能激活、清单注入、新增技能提醒、reload 结果全部落会话日志,重启后投影一致;损坏日志明确失败,不回退陈旧状态(延续 M05 语义)。技能命令经命令执行路径记录,与 M06 自定义命令的审计方式一致。
- N2 安全边界:技能加载全程只读,不新增任何写路径;技能文件位于技能目录之外(符号链接指向外部)的按 M06 loader 惯例处理;技能正文与清单进入会话时沿用现有会话消息的日志与脱敏管线,不因技能通道绕过;技能内容不构成验收证据,不触碰候选区、正式工程只读与网络授权边界。
- N3 归属隔离:技能按来源层级(项目/用户)区分并在列表中可见;项目级技能不跨项目可见;技能清单按会话快照,跨会话不共享激活记录。
- N4 可观察性:同名覆盖(项目>用户)、布局并存(SKILL.md>skill.yaml)、命令冲突跳过、异常文件跳过、fork 未启用报错、热更新结果均有明确可见反馈或日志,不静默吞掉。
- N5 有界性:目录扫描有界——目录深度、单文件大小、技能数量上限(量级对齐 M06 命令 loader 现有常量),超限跳过并报告;不可读、frontmatter 非法、正文缺失(布局②无 prompt.md 且 SKILL.md 无正文)的技能跳过且带路径原因出现在报告,不阻塞输入、不使 TUI 或服务崩溃;热更新检查轻量(mtime 对比),不在输入路径上做全量重扫。

## 不做的事

- 不做 fork 模式执行与子 agent 相关能力(留 M09);不为 fork 预留实现代码,仅字段解析与明确报错。
- 不做 InstallSkill 网络安装、技能市场、技能自动更新(推迟到后续小项)。
- 不做内置技能(源端内置技能为空,embed 机制不迁)。
- 不做技能的 tags 检索、过滤 UI 与标签管理(tags 仅解析保留,供展示)。
- 不做技能的参数类型校验与参数值自动补全(与 M06 自定义命令同界)。
- 不做技能正文的历史版本、差异对比与编辑 UI;技能文件由用户直接管理。
- 不做 MCP prompts 暴露为命令(M07-C)。
- 不改 M06 自定义命令的行为与优先级;`$ARGUMENTS` 渲染复用现有语义,不引入新模板语法。

## 验收标准

- AC1(对应 F1):两种布局的技能均被发现与解析;缺 name 回退目录名、缺 description 回退正文首行;同名技能项目级覆盖用户级、两种布局并存时 SKILL.md 优先,覆盖与并存均可在报告中观察到。
- AC2(对应 F2):每个技能注册同名斜杠命令并可执行,参数按 `$ARGUMENTS` 两种形态渲染;与内置命令、自定义命令文件同名时按「内置 > 命令文件 > 技能」跳过且冲突可观察;`/skills` 列表内容与实际技能一致,`/skills reload` 后数量变化可见。
- AC3(对应 F3):`LoadSkill` 对已知技能返回正文并产生激活;对未知技能返回明确错误并列出可用技能名;该工具在 chatserve 与 runtime 两处白名单可见。
- AC4(对应 F4):会话首次运行的上下文含技能清单段;会话进行中新增技能后,下一轮运行 agent 可感知该技能(系统提醒),同一技能不重复提醒;清单与提醒事件落会话日志,重启后投影一致。
- AC5(对应 F5):经斜杠命令或 `LoadSkill` 激活后,渲染正文作为用户消息进入当前会话且 agent 下一轮可见;激活记录随会话持久;触发会话压缩后,已激活技能仍可被 agent 感知。
- AC6(对应 F6):`mode: fork` 技能可被发现、列出,但经斜杠命令与 `LoadSkill` 调用均返回「子 agent 能力未启用」明确错误,不产生会话消息与激活记录。
- AC7(对应 N5):超限(深度/大小/数量)与异常(不可读、frontmatter 非法、正文缺失)技能被跳过,路径与原因出现在报告;TUI 与会话服务不崩溃,输入不被阻塞。
- AC8(热更新,对应 F1/F2):会话运行中修改技能正文后,下次调用即读到新正文;新增/删除技能目录后无需重启,命令补全与 `/skills` 列表即可感知;`/skills reload` 手动触发生效。
