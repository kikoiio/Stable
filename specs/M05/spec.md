# M05 会话与上下文 Spec（草案）

> 状态：已批准（2026-10-04）。依据迁移地图、M00 统一执行契约及用户对 /say、/reply 和 rewind 边界的选择；plan 已于 2026-10-04 批准。

## 背景

Stable 已按项目保存 append-only 会话事件日志，并可列出和恢复 transcript，记录 agent 流事件、工具调用和结果。上下文压缩目前主要覆盖普通聊天；agent 会话恢复会从事件日志投影上下文，但只保留最近消息，缺少可审计的持久压缩边界。输入历史、可搜索的会话恢复，以及与 agent 工作区绑定的文件快照和 rewind 尚未形成完整用户流程。

mewcode 提供持久会话、输入历史、上下文压缩与文件快照的行为参考。Stable 的实现必须服从统一执行契约：目标事实与验收结论由 Stable 保存；agent 对工程的改动留在隔离候选区，经受信接收后才进入正式工程。

## 目标

- 浏览、搜索并恢复会话，使 transcript 和 agent 上下文一致。
- 保存有界用户输入历史，重启后可恢复。
- 压缩 agent 上下文中的较早内容，保留近期原文和完整审计记录。
- 按会话和候选记录文件快照，允许安全回滚尚未接收的候选区。
- 为 /say 和 /reply 明确持久化、排队和恢复语义。

## 功能需求

- F1 会话浏览、搜索与恢复：按最近活动浏览会话，并按标题、首条用户消息或会话文本筛选。恢复时 transcript 顺序、工具调用/结果配对和运行归属一致。损坏日志要明确报错，不能悄悄展示旧上下文。
- F2 输入历史：按项目保存最近最多 200 条非空用户输入，连续重复项去重，可在输入框中浏览，重启后仍可用。输入历史与 transcript 分开保存，不作为模型上下文重放。
- F3 持久上下文压缩：agent 上下文接近模型安全阈值时，将较早的已完成对话压缩为摘要，保留近期消息原文，持久记录压缩边界。模型上下文可重复重建；未完成工具调用不能被摘要截断。压缩不删除原始审计事件。
- F4 文件快照：候选文件变化时，为其项目、会话和唯一候选记录可检查的快照，包含时间、关联输入或运行、路径及文件状态摘要。其他项目、会话或候选不能引用该快照。
- F5 候选区 rewind：用户可把同一会话、同一候选中尚未接收的内容回滚到选定快照。回滚前须确认写入者已停止并校验候选身份及快照摘要；结果和失败原因可观察、可恢复。rewind 不改正式工程，也不撤销已完成的受信接收。
- F6 /say 与 /reply：/say 把补充指令持久排入目标下一轮决策，不取消或并发重入当前运行；重启后继续按序处理。/reply 只回答 agent 明确提出且尚待用户回答的问题，并关联到对应待答项。没有可答问题时明确提示，不伪装成有效答复。
- F7 目标事实边界：会话压缩、快照和 rewind 不得改变验收标准、证据或目标 verified 结论。强制接收候选后仍需独立复核。

## 非功能需求

- N1 可靠恢复：持久事件沿用现有序号和校验；压缩或 rewind 中断后能检测并恢复，部分写入不能报告为成功。
- N2 范围隔离：路径操作经受信项目与候选边界检查；拒绝越界绝对路径、路径穿越和符号链接逃逸。
- N3 隐私：历史、摘要、快照元数据和恢复上下文遵循凭据脱敏及本地状态目录权限约束。
- N4 有界资源：输入历史、保留原文尾部、快照数及压缩输入都有上限，压缩不无界读取工程文件。
- N5 可观察性：压缩触发和边界、rewind 目标和结果均有明确状态，区分待处理、成功和失败。

## 不做的事

- 不回滚或改写正式工程，不绕过候选 review/accept。
- 不实现多 agent 团队、远程会话、跨项目共享或分支式会话历史。
- 不把输入历史或摘要用作目标证据、自动验收或持久记忆。
- 不实现 M06 的通用 plan/todo 界面；/reply 只为明确待答项提供协议兼容，不宣称尚未实现的提问 UI 可用。
- 不自动按会话年龄删除会话或快照。

## 验收标准

- AC1：创建并继续多个会话后重启 Stable，可搜索并恢复指定会话；transcript 顺序一致，工具调用均有对应结果，坏日志明确报错。
- AC2：输入超过 200 条命令，含连续重复项并重启；历史上限、去重、浏览顺序正确，恢复上下文时不把历史项当新消息。
- AC3：超过压缩阈值后，模型收到摘要和近期原文，工具往返完整；重启后上下文投影一致，压缩前事件仍可读取。
- AC4：在压缩边界持久化时注入失败并重启；系统报告失败或从完整边界恢复，不能把半条摘要当作成功结果。
- AC5：两个会话各自修改候选文件；快照只显示所属项目、会话和候选，重启后仍可见。
- AC6：对候选文件新增、修改、删除并建立快照后再回滚；候选恢复到快照，正式工程逐字节不变，快照之后创建的文件被移除。
- AC7：对已接收候选、其他会话候选、摘要已变化的候选、活动写入或越界路径请求 rewind；系统拒绝，或先完成可验证的受控停止并显示结果；正式工程不变。
- AC8：活动目标收到 /say 后，指令在下一决策轮按序消费，当前轮不被暗中取消或并发；/reply 只回答对应待答问题。重启后不丢失、不重复消费，也不能回答不存在或已完成的问题。
- AC9：目标工作项执行恢复、压缩和候选 rewind 后，验收标准与证据保持正确；人工强制接收不把目标置为 verified。
- AC10：Go 构建、vet、相关单测及会话/候选端到端检查通过，既有 M00–M04 行为保持可用。

## 草案默认值

输入历史上限和项目级存储沿用源端当前行为。历史只过滤连续重复项；完整会话事件保留供审计，模型上下文由压缩投影构造。rewind 只作用于未接收候选区；活动写入须先可验证地停止，状态不确定时拒绝并保留现场。
