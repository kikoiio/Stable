# M04 基础工具 Spec

> 状态：已批准（2026-10-04）。依据：[迁移地图 M04 行](../../mewcode-migration-map.md)、[M00 统一执行契约](../M00/unified-execution-v1.md)、[M03 收尾处置](../M03/checklist.md)。

## 背景

M00 契约确立普通任务与目标工作项共用同一 agent 执行能力；M02 提供流式模型对话与共享 runner；M03 建立了不可绕过的权限、Linux 隔离与候选受控接收闭环（C01–C36 已验收）。当前统一 agent 运行器收到模型工具调用后停在 awaiting_tools，不执行任何工具：模型无法读取工程、检索内容或修改候选区，普通任务与目标工作项都无法完成真实工作。

迁移地图 M04 行要求：接入读写编辑文件、搜索、列目录、命令、diff、工具搜索、媒体输入等基础工具，逐类接入并记录工具调用、结果、失败与预算；通用工具复用 M03 的权限、隔离和受信接收边界，目标工作流只能通过受控执行入口使用工具。

经澄清确认的关键行为：

- 读文件、列目录和内容搜索只读取授权范围内的正式工程只读视图。
- 写文件和编辑文件只写入本次运行的隔离候选区；候选接收前正式工程不改变。
- 工具调用轮数按模型工具回合计数：一次模型响应包含一个或多个工具调用时计为一轮；总运行时长另设上限。
- M03 遗留的 S01 案例运行器重写纳入本里程碑。

经澄清确认的范围取舍：

- 工具清单取核心六类 + diff（读文件、列目录/文件匹配、内容搜索、写文件、编辑文件、受控命令）；tool_search（工具检索）与 media_input（媒体输入）推迟——前者在无 MCP/延迟工具前没有真实消费者（归 M07），后者依赖多模态输入管线。
- 预算语义取「运行级执行预算」：记录每步调用并设运行级上限，超限自动停止并说明原因；不做模型费用统计，不做工具结果磁盘溢写（mewcode toolresult 语义留 M05 一并决策）。
- 实施路线：整包移植 mewcode-golang `internal/tools` 包并适配本仓边界（仅入册核心六类+diff，其余工具文件不移植）。
- M03 残留 1（依赖不可用窗口后唤醒重放失效）已于 2026-10-04 解决并合入主线（提交 1d64bc0：定位为测试收敛判定竞态而非产品回归，dependency_change 尾部三阶段恢复全绿）——写入/命令工具接入的追加门槛已解除，不属于本里程碑任务。
- M03 残留 4：S01 案例运行器重写纳入本里程碑收尾。

## 目标

- 模型在普通任务和目标工作项中可调用一套基础工具，多轮循环直至完成、取消或预算超限
- 全部工具调用复用 M03 的权限、隔离与候选受控接收边界；写入只落候选区，正式工程在接收前逐字节不变
- 每步工具调用、结果、失败与耗时被记录并可按运行追溯
- 编辑类工具结果附带精确 diff 摘要，供对话上下文与界面展示
- M04 收尾按会话绑定目标 + 接收流程重写 tests/cases 案例运行器

## 功能需求

- F1 工具循环：运行器收到模型的工具调用后，经统一受控执行入口执行并将结果回填对话，继续多轮直至模型不再发起工具调用、用户取消或预算超限。循环期间运行状态（执行中、等待授权）在统一事件流中可观测。
- F2 基础工具集（对普通任务与目标工作项可用）：
  - F2a 读文件：按路径读取文本内容，带行号，支持从指定行起分段读取
  - F2b 列目录与文件匹配：按模式列出文件与目录
  - F2c 内容搜索：在授权范围内按文本/正则搜索文件内容
  - F2d 写文件：在候选区创建或覆盖文件
  - F2e 编辑文件：在候选区内做精确字符串替换
  - F2f 受控命令：在隔离沙箱内执行 shell 命令，有超时上限
  - F2g diff 摘要：写/编辑类工具结果附带精确 diff 文本与增删行数统计
- F3 权限与授权边界：每次工具调用经 M03 权限入口评估（四种模式、精确规则、待授权提示与一次性批准语义不变）；文件与命令访问限定在授权根与候选区内；未授权或越界请求被拒绝且原因可观测。
- F4 隔离执行：工具执行处于 M03 已验证的 Linux 隔离边界内；隔离不可用时拒绝工具执行且无宿主回退；取消或超时终止工具进程及其子进程，不留残留。
- F5 记录与追溯：每次工具调用记录工具名、参数摘要、结果状态（成功/失败/被拒/超时）、耗时与结果规模；可按运行回放查看；工具输出中的凭据类信息不进入持久记录。
- F6 运行级执行预算：每次运行设有工具调用轮数与总时长上限（可配置）；超限自动停止运行，事件与状态说明停止原因；未超限时不误停。
- F7 两类任务一致性：普通任务与目标工作项经由同一工具执行入口与相同的权限/预算语义；目标工作流的工具使用只能通过受控执行入口，无旁路。
- F8 测试基建：提供确定性的 fake 工具执行器（不依赖真实沙箱与模型）供单元/集成测试与场景用例使用；e2e 场景覆盖「调查→修改→候选→接收」流程。
- F9 S01 案例运行器重写：按「会话绑定目标 + 候选接收流程」重写 tests/cases 运行器，在工具能力齐备后可运行 S01 修复案例。

## 非功能需求

- N1 回归安全：不破坏 M01–M03 既有功能；`go build`/`go vet`/`go test`、现有 e2e 场景与 Python 桥接测试保持通过。若本里程碑修改 store schema，须按 M03 残留 5 处置顺带补齐 v4/v5/v7/v9 连续迁移用例。
- N2 上下文保护：单条工具结果进入对话和持久记录前有输出上限，超长内容截断并注明；不做磁盘溢写。
- N3 凭据不泄露：模型凭据、宿主秘密和注入的敏感标记不得进入工具环境、沙箱挂载、授权提示、工具输出、运行事件、候选文件或持久记录（延续 M03 C16 语义）。
- N4 平台：首发 Linux；隔离依赖真实 Linux namespace，受限环境下按 M03 语义拒绝而非降级。
- N5 可恢复与可取消：等待授权时用户可取消；重连后运行状态、工具执行事件和待授权请求可按游标恢复显示；取消、超时和进程异常不留下可继续执行的工具进程。
- N6 一致性与幂等：候选接收前正式工程保持不变；正式工程只能由既有受信接收流程更新；重复接收请求不得重复应用同一候选变更。
- N7 读取写入视图一致：读、列、搜只使用授权正式工程只读视图；写、编辑只使用候选区；模型可见路径均为工作区相对路径，绝对路径、`..` 和符号链接逃逸必须被拒绝。
- N8 结果可解释：工具失败、拒绝、超时、隔离不可用和预算耗尽均返回稳定状态和可读原因，不能只表现为无结果或通用错误。

## 不做的事

- 工具检索与媒体输入：`tool_search` 推迟到 M07；`media_input` 推迟到后续多模态输入管线确定后再定。
- 其他工具：`ask_user`、`exit_plan_mode` 推迟到 M06；`mcp_call` 推迟到 M07；worktree 系列工具推迟到 M09。
- 预算与结果存储：不实现模型费用统计、工具结果磁盘溢写、结果聚合预算或完整上下文管理；相关会话与上下文语义留给 M05。
- 正式工程写入：工具不能直接修改正式工程；agent 不能自行接收候选、伪造用户审批或扩大权限范围。
- 会话与目标语义：不修改会话持久化、恢复、压缩和 rewind 语义；不修改目标调度、评估、会话转向或独立验证语义，M03 残留 2 作为 M05 规格输入。
- M03 已完成事项：不重新实现唤醒重放修复；该问题已在提交 `1d64bc0` 解决。不重新设计 M03 的权限、隔离、候选审阅和受控接收协议，只复用其边界。
- 平台范围：首发不支持 macOS 和 Windows；不提供绕过 Linux 隔离、授权目录、候选接收或受信控制面的降级路径。
- 并发优化：同一模型回合中的多个工具调用先串行执行；工具并发、后台工具和协作工作树留给后续里程碑。

## 验收标准

- AC1 普通任务端到端：用户提交任务后，agent 多轮调用读、搜、列工具调查 fixture 正式工程，用写、编辑工具产生候选，期间至少一次受控命令调用且输出回到对话；候选经检查和预览，用户接收后正式工程改变且仅改变一次；全程 TUI 可见工具调用事件流。
- AC2 读写边界：读、搜、列只能看到授权范围内的正式工程只读视图；候选接收前正式工程逐字节不变；写入和编辑仅落候选区；越界路径、符号链接逃逸和未授权写入被拒绝并显示原因。
- AC3 权限矩阵：四种权限模式下读、写、命令操作的允许、询问、拒绝结果符合 M03 询问表；保存的精确规则仅对相同操作、参数与范围复用，参数或范围变化后重新询问。
- AC4 隔离与清理：工具执行于真实 Linux 隔离环境内，正式工程以只读方式可见、候选区可写，授权根之外内容不可见；隔离不可用时拒绝执行且无宿主回退；取消或超时后无残留进程；工具输出、候选文件与持久记录不含注入的哨兵密钥。
- AC5 预算：注入模型工具回合或总时长超限场景后运行自动停止，终态和事件说明停止原因；未超限的正常多轮任务不误停。
- AC6 记录回放：按运行查询工具调用记录，名称、参数摘要、状态、耗时、结果规模与实际执行一致；断线重连后按游标恢复工具事件；超长结果在对话和记录中被截断并注明。
- AC7 目标工作项：目标工作项运行可调用同一工具集，对同类操作的权限、隔离、预算和候选结果与普通任务一致；候选接收后目标仍按 M00 语义等待独立复核。
- AC8 diff 摘要：写入和编辑结果展示的 diff 文本、新增行数和删除行数，和候选预览中的实际差异一致。
- AC9 回归：`go build ./...`、`go vet ./...`、`go test ./...` 退出 0；既有 e2e 场景、两个桥接目录的 Python 测试、打包测试和 fake 执行器驱动的集成场景通过。
- AC10 S01 案例运行器：重写后的运行器可在能够创建 namespace 的 Linux 环境跑通 S01 案例的“会话绑定目标 → 工具执行 → 候选审阅 → 受控接收”流程，退出码为 0，正式工程仅改变一次。
