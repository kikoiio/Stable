# M06 计划与任务交互 Spec

> 状态:已批准(2026-10-05)。依据迁移地图 M06 行、M00 统一执行契约,以及用户对范围(五项全做)、命令边界(含热更新)、plan 落点(项目 `.stable/plans/`)与提案确认弹窗化的澄清选择;plan/task/checklist 待批。

## 背景

Stable 经 M00–M05 已具备统一 agent 执行、权限审批弹窗、持久会话与提问答复协议,但通用 agent 的计划、任务和提问尚不可操作:`plan` 权限模式只有枚举没有运行时行为(M03 明确留给 M06);`ask_user`、`exit_plan_mode`、todo 工具在 M04 被明确推迟;slash 命令硬编码在补全与分发两处、无注册表,不支持自定义;目标提案确认只有文本命令。M05 已冻结 `PendingQuestion/Reply` 协议字段,明示提问产生方由 M06 建立。mewcode 源端在 commands、planfile、todo、ask_user、exit_plan_mode 五个模块提供完整行为参照(其自定义命令为启动时加载,M06 的热更新为超出源端的增强)。

## 目标

- 斜杠命令统一注册表,支持项目级与用户级自定义命令,文件变更无需重启即生效。
- 计划模式可进入、可退出:agent 受控写计划文件,经审批弹窗批准后按所选模式执行。
- 建立提问产生方:`ask_user` 弹窗与答复链路,复用 M05 提问协议。
- agent 可维护任务清单(todo),按会话持久并可见。
- 目标提案确认弹层化,状态机与标识(prop-XXX)不变。
- 多类待决策弹层按固定优先级排队呈现。

## 功能需求

- F1 斜杠命令体系:内置命令迁入统一注册表(名称、描述、别名、类型、参数提示),补全与执行都来自注册表。自定义命令为磁盘 `.md` 文件,扫描项目 `.stable/commands/` 与用户级 `~/.config/stable/commands/`,项目同名覆盖用户级;子目录映射为 `命名空间:命令名`;frontmatter 支持 description / argument-hint / aliases;正文为提示词模板,`$ARGUMENTS` 替换参数,无占位符时参数附加到正文。自定义命令与内置命令同名时不注册(内置优先)且可观察。提供 `/help` 列出全部可用命令。命令文件新增、修改、删除后无需重启,补全与执行即可感知。自定义命令执行等于把替换后的提示词作为用户消息进入当前会话。
- F2 计划模式:`/plan` 在当前会话切换计划模式与非计划模式,进入时创建或复用当前计划文件。计划模式下 agent 收到计划工作流提示(先调研、写计划、再请求批准);读操作放行,候选区写入与命令执行仍按权限策略询问;唯一免询问的写路径是当前会话的计划文件,且仅限项目 `.stable/plans/` 内该文件。计划文件持久化前脱敏,不受候选 rewind/接收影响。权限模式是会话运行时状态,重启回到默认,不持久化。`exit_plan_mode` 工具无参数;非计划模式调用报错;调用即请求用户批准计划。
- F3 计划审批弹窗:agent 请求批准后 TUI 弹出计划审批弹层,三选项:自动接受(后续运行切换为「范围内写自动允许、命令仍询问」的执行模式,正式工程仍只读、写仍进候选区)、逐次确认(后续运行保持默认模式)、反馈继续改(输入纠偏文本,保持计划模式)。计划提交、批准、取消、反馈均落会话事件,transcript 可见、重启可投影。计划审批与目标提案保持独立标识与状态。
- F4 提问弹窗:`ask_user` 工具支持 1–4 个问题、每题 2–4 个选项、可选多选,自动附「其他」自由输入。运行中调用即产生待答问题(落 M05 协议事件),TUI 弹出提问弹层,agent 运行暂停等待。答复可经弹层提交(选项或自由文本),也可经 `/reply` 文本答复;答复一次性消费,agent 收到后继续。运行已结束(取消/崩溃/完成)时遗留的待答问题仍可答复,答复作为会话消息排队,下次运行进入上下文(与 `/say` 语义一致)。
- F5 任务清单:agent 经 todo 工具(创建/查询/列出/更新)维护当前会话的任务清单;任务含主题、描述、状态(pending/in_progress/completed)与依赖(Blocks/BlockedBy)。存储于项目 `.stable/tasks/`,按会话隔离,一个会话一个列表,重启后恢复。每次变更落会话事件,transcript 渲染变化。todo 与 Stable 目标(Goal)及其工作项无关,不占用目标提案标识。
- F6 目标提案确认弹窗:会话中生成待确认的目标提案时,TUI 弹出提案弹层,展示验收标准全文,提供 确认/拒绝/稍后 三选项;确认与拒绝走现有 `/confirm` `/reject` 同一状态机。稍后处理则关闭弹层,提案保持 pending,文本命令始终可用。恢复会话时存在 pending 提案的不自动弹层,transcript 可见、命令可处理。

## 非功能需求

- N1 一致性与审计:命令执行、模式切换、计划审批、提问答复、提案确认全部落会话日志,重启后投影一致;损坏日志明确失败,不回退陈旧状态(延续 M05 语义)。
- N2 安全边界:plan 文件免询问写白名单仅限当前会话计划文件这一个路径,不得泛化为 `.stable/plans/` 全目录;计划文件、任务清单、自定义命令的读写不得触碰正式工程只读、候选区隔离与网络授权边界;plan 文件与 todo 落盘前应用凭据脱敏,无法安全脱敏时拒绝写入。
- N3 归属隔离:计划文件按会话归属、任务清单按会话归属、自定义命令按项目/用户级来源区分;跨项目、跨会话不可引用对方的计划与任务。
- N4 可观察性:未知命令、同名冲突被拒的自定义命令、热更新结果、弹层决策与取消都有可见反馈或日志;提问等待期间的资源行为与现有审批等待一致(不无界轮询)。
- N5 有界性:命令目录扫描与热更新检查有界(目录深度、文件大小、命令数量上限),异常文件(不可读、frontmatter 非法)跳过并报告,不阻塞输入或不使 TUI 崩溃。

## 不做的事

- 不做 MCP、skills、hooks 及其与命令的关联、技能目录发现、`/skills` 命令(M07)。
- 不做非交互 print 与远程入口的弹窗等价呈现(M10);协议与事件字段不绑定 TUI,供 M10 复用。
- 不做计划文件的多计划管理、历史版本与差异对比 UI;单会话单当前计划。
- 不做 todo 的多列表切换、跨会话汇总视图、任务指派给多个 owner。
- 不改目标提案的状态机、标识与独立验收语义;不把计划审批结果或 todo 状态用作验收证据。
- `ask_user` 不支持超过 4 题、每题超过 4 选项(照源端上限)。
- 计划模式不新增免询问的网络访问或命令执行能力。
- 不做自定义命令的参数类型校验与参数值自动补全(argument-hint 仅作提示展示)。

## 验收标准

- AC1:补全列表来自注册表;内置与自定义命令均可补全并执行;新增/修改/删除 `.md` 命令后无需重启生效;`$ARGUMENTS` 替换与无占位符附加两种形态正确;同名冲突内置优先且可观察;`/help` 输出与实际可用命令一致。
- AC2:`/plan` 进入计划模式后:读放行、候选区写与命令仍询问、仅当前计划文件写入免询问;越出该路径的写请求仍走审批;非计划模式下调用 `exit_plan_mode` 报错;重启后回到默认模式。
- AC3:`exit_plan_mode` 触发审批弹层;三选项分别产生「acceptEdits 语义执行 / 默认模式执行 / 保持计划模式并收到反馈文本」三种可观察后续;决策事件落日志,重启投影一致。
- AC4:`ask_user` 弹层正确呈现 1–4 题、2–4 选项、多选与「其他」;弹层答复与 `/reply` 答复都使问题置为已答且 agent 继续;无待答问题时 `/reply` 带无效 question id 被拒绝;运行结束后遗留问题答复进入排队消息。
- AC5:todo 四工具增改查与依赖字段正确;重启后当前会话清单恢复;每次变更在 transcript 可见;todo 文件不进候选区、不受 rewind 影响。
- AC6:提案弹层确认/拒绝与文本命令到达同一状态机结果(状态、revision、消息一致);「稍后」不改变提案状态;pending 提案在 transcript 可见。
- AC7:权限审批、提问、计划审批、提案确认同时待决策时按「审批 > 提问 > 计划审批 > 提案」顺序排队呈现;退出当前弹层可处理下一个;全部决策可审计。
