# M01 共用 TUI 外壳 Spec

## 背景

Stable 当前 TUI 用三栏同时展示会话、聊天和长期目标，输入为单行文本；mewcode 提供以对话为主的终端界面，包含消息滚动、多行输入、Markdown、状态提示、快捷键与输入补全。mewcode 的 TUI 主模型与 agent、工具、权限等模块紧密耦合，不能整文件替换。

M00 已确认普通任务与长期目标使用同一套 agent 执行能力，并通过同一终端界面访问。M01 将 Stable 当前三栏 TUI 改为以 mewcode 对话主视图为交互基线，迁入可复用的终端输入、滚动与呈现交互；在同一 TUI 内保留 Stable 的会话/长期目标入口，并为后续 agent 事件、候选接收和目标证据提供界面承载。M01 只建立外壳和基础交互，运行流、权限等能力由后续子项目逐项接入。

## 目标

- 建立以对话为中心、可进入会话和长期目标的共用 TUI 外壳。
- 迁入 mewcode 中可独立复用的终端输入、消息视窗、Markdown 与补全交互。
- 为运行状态、候选审阅、目标状态及证据提供一致的界面承载方式，不提前宣称后续能力已可用。
- 首发平台为 Linux，沿用 Stable 当前 Bubble Tea/Lipgloss 技术栈。

## 功能需求

- **F1 对话主视图**：以对话内容为主视图；同一 TUI 内可进入会话导航和长期目标视图，不要求启动另一程序。终端变窄时仍能使用基本导航和输入。
- **F2 多行输入**：提供随内容调整高度的多行输入框；Enter 提交，Ctrl+J 插入换行。未提交输入在终端尺寸变化和视图导航时保留。
- **F3 消息呈现**：消息视窗支持滚动、继续阅读长对话，并以终端样式呈现 Markdown。长消息不被压缩为单行摘要。
- **F4 会话与目标入口**：可导航会话并查看其消息；可查看长期目标状态、摘要与证据入口。M01 不要求呈现尚未接入的流式工具事件。
- **F5 状态与快捷键提示**：显示当前会话/目标上下文、焦点操作提示、加载状态和错误反馈；闲置、加载、失败状态可区分。
- **F6 输入补全**：输入斜杠前缀时可筛选和选择当前已实现的命令；输入 `@` 路径前缀时可筛选项目文件路径并插入所选路径。未实现命令不显示为可用候选。
- **F7 弹层承载**：界面提供可复用的弹层承载方式，正确调整主视图；权限、计划审批和提问弹层仅在对应后续子项目实现后提供实际操作。

## 非功能需求

- **N1 平台与技术栈**：首发运行于 Linux 终端，沿用项目现有 Bubble Tea/Lipgloss 技术栈。
- **N2 尺寸适配**：终端尺寸变化时消息视窗和输入区重新布局，未提交输入与当前导航状态不丢失。
- **N3 小窗口可用性**：窄窗口仍可完成基本会话/目标导航与输入；低于可用尺寸时显示清楚的放大提示。
- **N4 无颜色可辨识**：颜色不可用时仍可区分消息、焦点、状态和错误，不以颜色作为唯一标识。
- **N5 状态清晰**：加载、失败和普通闲置状态明确区分；快捷键提示与实际操作一致。
- **N6 不展示未交付能力**：不显示尚未实现的命令或弹层操作，不让用户误以为已交付 agent 流式运行或权限控制。

## 不做的事

- 不接入 mewcode 的完整 agent 运行循环、流式工具事件或模型后端；这些由 M02 及后续项目实现。
- 不在本阶段实现权限决策、计划审批、提问流程、MCP、skills、hooks 或自定义命令执行；本阶段仅建立弹层和输入补全的承载交互，相关行为随后按 M03、M06、M07 接入。
- 不修改目标执行、验收、证据、存储格式或长期调度机制。
- 不逐文件照搬 mewcode 的 TUI 主模型；只迁入能独立复用且符合 M00 契约的交互。
- 不纳入 macOS/Windows 首发支持。

## 验收标准

- **AC1（F1）**：启动后进入以对话为主的界面；从同一 TUI 可进入会话导航和长期目标视图，不需启动另一程序。
- **AC2（F2）**：输入多行内容后，输入框随内容增高；Ctrl+J 插入换行，Enter 提交；调整窗口或切换导航时，未提交文本保留。
- **AC3（F3）**：历史消息可在滚动视窗中阅读；Markdown 标题、列表、代码块等按终端样式呈现，长消息不会被截成单行。
- **AC4（F4）**：选择会话可查看消息；选择目标可查看状态、摘要和证据入口。M01 不要求显示尚未接入的流式工具事件。
- **AC5（F5）**：状态栏显示当前会话/目标上下文、焦点操作提示，以及加载和错误状态；闲置、加载、失败有不同提示。
- **AC6（F6）**：输入斜杠前缀或 `@` 路径前缀时，可筛选、选择并补全当前已实现的命令或项目文件路径；未实现命令不出现在候选中。
- **AC7（F7）**：界面能承载通用弹层内容并正确调整主视图；M01 不显示未接入的权限、计划或提问操作。
- **AC8（N1–N3）**：Linux 终端调整尺寸后布局重排；在小于可用阈值时提示放大窗口，输入与导航状态不丢失。
- **AC9（N4–N6）**：禁用颜色时仍可辨识焦点、状态和错误；快捷键提示与实际行为一致，且没有未实现功能的可操作入口。
- **AC10（范围）**：交付仅包含共用界面外壳和基础交互；模型流、权限控制或工具循环没有被标记为 M01 已交付能力。
