# M08 记忆与指令发现 Spec

> 状态：实施完成并验收通过（2026-10-07）。逐项结果与验证证据见 [checklist.md](checklist.md)。

## 背景

Stable 已有统一 agent 执行、工具权限、会话持久化与压缩，以及 skills、hooks、MCP 扩展，但还没有通用的指令发现和记忆系统。Mewcode 源端提供分层指令加载、用户级与项目级记忆、相关记忆召回、自动提取和后台整理作为行为参照。Stable 的目标、验收标准、证据和结论仍由持久目标事实管理，不能由记忆替代或修改。

## 目标

- 按源端分层规则发现用户级和项目目录中的指令文件，支持受限 `@include`。
- 提供用户级和项目级持久记忆；每次运行加载索引，并根据当前请求选择相关记忆供普通会话和目标工作项使用。
- 允许 agent 主动写入记忆，并在每轮运行后后台提取；目标工作项只可提取用户偏好、项目背景和参考，不提取目标、标准、证据或验收结论。
- 距上次整理至少 24 小时且累计至少 5 个会话后，后台整理记忆。
- 提供记忆列表、按条目删除和清理命令；清理默认限当前项目，用户级或全部清理需显式指定。项目级记忆保存在项目目录，是否提交由项目自行决定。

## 功能需求

- **F1 指令发现与优先级**：每次 agent 运行前发现指令文件。用户级读取 Stable 用户配置目录下的 `STABLE.md`、`AGENTS.md`；从项目根目录到工作目录逐层读取 `STABLE.md`、`AGENTS.md`、`.stable/STABLE.md`；最后读取工作目录的 `STABLE.local.md`。按此顺序合并，越具体的文件越后加载、优先级越高。非 Git 工作目录以工作目录作为项目根。
- **F2 指令 include**：支持 `@./path`、`@../path`、`@~/path` 和 `@/absolute/path`，相对路径以包含它的文件所在目录解析。只允许读取项目根目录或用户级 Stable 配置目录中的文件；拒绝越界路径和符号链接逃逸。代码围栏中的 `@` 行不展开；循环引用、重复引用与超过 5 层的嵌套不得导致递归；无法读取或解析的 include 保留原行并可观察。
- **F3 记忆目录与分类**：用户级记忆存于 Stable 配置基目录下的 `stable/memory/`，项目级记忆存于 `<项目根>/.stable/memory/`。记忆以带元数据的 Markdown 文件保存，每个目录的 `MEMORY.md` 是索引。`user`、`feedback` 类型归用户级；`project`、`reference` 类型归项目级。项目级记忆是否纳入版本控制由项目决定。
- **F4 运行时上下文**：每次普通会话和目标工作项运行都加载两级 `MEMORY.md` 索引，并把已发现的指令和索引注入 agent 上下文。索引每个最多加载 200 行；截断时给出明确提示。记忆只能作为上下文，不能成为 Stable 目标事实或验收证据。
- **F5 相关记忆召回**：根据当前请求和两级记忆清单，通过配置的模型服务选择相关记忆，只将被选中文件的正文加入本次上下文；每条记忆标明来源范围和更新时间。当前运行无法召回记忆时，agent 仍继续工作，并记录可观察的失败状态。
- **F6 记忆读写边界**：agent 可查看、创建、更新或删除两级记忆目录中的记忆文件及索引。该能力不得扩大到记忆目录之外；项目代码和正式工程的写入仍遵循既有候选、权限和接收边界。明确请求“记住”或“忘记”时，agent 应立即保存或移除对应记忆。
- **F7 每轮自动提取**：每次普通会话或目标工作项运行结束后，后台检查本轮新消息并提取有长期价值的用户偏好、反馈、项目背景或参考信息；若主 agent 本轮已写入记忆，则跳过重复提取。提取不得阻塞当前交互。目标工作项中的目标描述、验收标准、进度、证据和结论不得写入记忆。
- **F8 后台整理**：距上次成功整理至少 24 小时，且之后已有至少 5 个不同会话，才可启动整理。整理可合并重复项、更新过时内容、处理索引；同时只允许一个整理任务运行。整理结果和失败原因可观察，不改变目标或验收事实。
- **F9 记忆管理命令**：`/memory list` 列出两级记忆的名称、类型、描述和范围；`/memory delete <scope> <entry>` 按明确范围与条目删除记忆并更新索引；`/memory clear` 默认清除当前项目记忆，显式指定 `user` 或 `all` 后才清除用户级或两级全部记忆。删除结果和错误可观察。

## 非功能需求

- **N1 路径安全与权限**：用户级记忆目录仅当前用户可读写；项目指令、include 和记忆文件必须留在允许的项目根/用户配置范围内。路径穿越、符号链接逃逸和非普通文件均拒绝。agent 对记忆目录的写权限不得扩大到其他项目文件。
- **N2 信息使用边界**：记忆内容是可能过时的上下文，不是事实凭证；不能创建或改变 Stable 的目标、验收标准、证据或验证结论。当前请求与记忆清单、被选中的记忆正文，以及自动提取/整理所需的会话内容和记忆内容，会发送到用户已配置的模型服务；不通过 M08 同步到其他云端存储。用户可以查看并删除两级记忆。
- **N3 有界资源**：每个指令文件和记忆文件最多读取 1 MiB，include 嵌套最多 5 层；每级最多扫描 200 个记忆文件，frontmatter 最多读取 30 行；每次召回最多选 5 条。每个 `MEMORY.md` 最多注入 200 行且不超过 25 KB，超限明确提示截断；超大记忆文件跳过并报告。
- **N4 失败隔离**：损坏或越界文件、无效元数据、模型选择失败不得使会话或目标运行崩溃。召回失败时继续运行且不注入记忆；自动提取或整理失败时报告失败，不声称已保存或整理成功。
- **N5 过期提示**：召回的记忆显示其范围与更新时间；超过一天的记忆须提示它可能过时，并要求 agent 在作为当前事实使用前进行核实。
- **N6 后台任务不阻塞**：自动提取与整理不阻塞用户交互；同一记忆范围不得并发运行冲突的整理任务；后台任务应有界结束并提供成功、跳过或失败状态。
- **N7 持久性边界**：记忆独立于会话压缩和会话恢复，除非用户通过记忆管理命令删除，不得被压缩、恢复或候选回滚隐式改写或清除。

## 不做的事

- 不把记忆用作目标事实、验收标准、证据、审核意见或验证结论；这些仍由 Stable 持久化。
- 不实现通用子 agent、团队、后台任务编排或工作树；M08 的提取和整理仅限记忆目录的受限后台操作，不对外提供通用协作能力。
- 不提供向量数据库、embedding 检索、外部知识库或跨项目项目记忆。用户级记忆可跨项目使用；项目级记忆只属于当前项目。
- 不提供云端记忆同步、跨设备同步、记忆市场或外部安装。
- 不自动提交或暂存项目记忆；是否纳入版本控制由项目自行决定。
- 不迁移旧 Mewcode 记忆数据，也不提供记忆文件编辑器、历史版本或恢复界面；用户通过文件和 `/memory` 命令管理。
- 不按年龄自动删除记忆；过期记忆由后台整理或用户显式删除。

## 验收标准

- **AC1（F1）**：在临时项目中分别创建用户级、项目根、子目录和工作目录指令文件；agent 上下文按规定顺序包含它们，较具体文件优先。修改文件后下一次运行读到新内容；非 Git 工作目录也能从工作目录加载。
- **AC2（F2）**：验证相对路径、`~/` 与项目内绝对路径的 include 可展开；代码围栏不展开；循环、重复、超深嵌套、越界路径和符号链接逃逸不会读取未授权文件，问题可观察。
- **AC3（F3）**：分别创建四种类型记忆，验证分类路由到用户级或项目级目录、`MEMORY.md` 索引可更新、列表显示正确范围；程序不自动暂存或提交项目记忆。
- **AC4（F4、F5）**：普通会话和目标工作项运行都加载两级索引；召回器最多选择 5 条，模型只收到被选中记忆正文，并看到范围、更新时间及旧记忆提示。选择失败时当前运行继续且无记忆注入。
- **AC5（F6、F9）**：agent 可在用户级和项目级记忆目录读写；对其他路径的写入仍受原边界控制。`/memory list`、按范围删除、默认项目清理以及显式 `user`/`all` 清理均有正确结果，并同步更新索引。
- **AC6（F7）**：结束普通会话运行后，后台提取可保存符合类型的长期信息且不阻塞交互；若主 agent 本轮已写入记忆，提取器不重复写入。后台失败不会报告成功。
- **AC7（F7）**：目标工作项运行可提取用户偏好、项目背景和参考，但提供目标描述、标准、进度、证据、结果作为输入时，这些目标事实不会写入记忆，且 Stable 的持久目标状态保持不变。
- **AC8（F8）**：分别验证未满 24 小时、会话数少于 5 时不会整理；两个门槛都满足后会整理并给出结果。并发触发时最多一个整理任务运行，失败可观察。
- **AC9（N1、N2）**：路径穿越、越界 include、符号链接逃逸、伪造记忆路径写入均被拒绝；记忆变更无法修改目标标准、证据或验收结论。
- **AC10（N3、N4、N6）**：超限指令、记忆索引和记忆数量按上限截断或跳过并可观察；文件解析、选择器或后台任务失败时，主会话和目标运行仍可继续。
- **AC11（N7）**：压缩、恢复和候选回滚后，未显式删除的记忆仍存在且可再次召回；清除记忆不会更改会话日志中的目标事实。
- **AC12（端到端）**：在嵌套项目中运行 agent，验证用户级与项目级指令加载、相关记忆召回、记忆自动提取和下一会话恢复；再运行一个目标工作项，确认它能读取相关记忆，但目标标准、证据和验收状态没有因此变化。

## 草案默认值

- 指令文件名、发现顺序及 include 边界按 F1、F2 所列规则执行；指令每次运行重新发现，修改在下一次运行生效。
- 记忆目录依 Stable 的用户配置目录及当前项目根解析；项目记忆仅在当前项目可见，用户记忆跨项目可见。
- 后台整理的 5 个会话按当前项目中上次成功整理后有活动的不同会话计算；整理操作同时检查用户级和当前项目级记忆，但不会读取其他项目的会话。
- 记忆清单选择、记忆正文注入、自动提取和整理仅使用用户已配置的模型服务；选择器或后台任务失败时采用 N4 的失败隔离行为。
